# Groq quick setup
1. In accessable-ai/.env.local keep your GROQ_API_KEY and Supabase variables.
2. Set GROQ_MODEL=openai/gpt-oss-20b
3. Stop the old Next.js server with Ctrl+C.
4. Run npm.cmd install, npm.cmd run build, npm.cmd run dev.
5. Sign in before using Generate AI fixes.
6. Click Analyze code first for local checks; AI fixes are separate.
If AI fails, read the red error under Generate AI fixes and server terminal.
